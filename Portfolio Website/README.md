# Portfolio Website

A static personal portfolio site built with plain HTML, CSS and JavaScript.

## Pages

| Page | File |
|------|------|
| Home | `index.html` |
| About | `about.html` |
| Work | `work.html` |
| Project case study | `project.html` |
| Services | `services.html` |
| Service detail | `service.html` |
| Blog | `blog.html` |
| Blog article | `article.html` |

## Data

Content lives in JavaScript files so pages stay simple:

- `data.js` – shared site data
- `cases.js` – project case studies
- `articles.js` – blog articles
- `services-detail.js` – service details

## Run locally

Open `index.html` in a browser. No build step is needed.
